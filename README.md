- 👨‍💻 Lightweight and portable — no heavy dependencies.

## 📂 Included Tools - Based on Local FFmpeg
- `FFmpeg Latest Version Auto Downloader.bat` → Auto download binary files
- `Video Format Converter.bat` → Convert any type video file format
- `Video Ratio Converter.bat` → Video aspect ratio converter horizontal to vertical
- `Video to Audio Converter.bat` → Video to mp3 converter
- `Remove Audio from Videos.bat` → Sound Remove from bulk videos
- `Add Music to Silent Videos.bat` → Sound add into bulk videos
- `Replace Audio Track in Videos.bat` → Old music replace with new sound
- `Join Multiple Audios.bat` → Merge multiple audio clips into one long audio file
- `Join Multiple Videos.bat` → Merge multiple video clips into one long video file
- `Audio Sequence Cutter.bat` → Cut long audio files into multiple segments
- `Video Sequence Cutter.bat` → Cut long video files into multiple segments
- `Frame-by-Frame Image Extractor.bat` → Extract video frames as images
- `Create Short Videos From Images.bat` → Convert image sequences into custom duration short videos
- `Create Long Videos From Images.bat` → Convert image sequences into custom duration long videos
- `Create Long Videos With Loop.bat` → Loop smaller video to create long-duration videos
- `Create Long Videos With SlowMotion.bat` → Create longer videos by applying slow-motion effect
- `Remove Noise from Audios.bat` → Clean background noise from audio tracks
- `Remove Noise from Videos.bat` → Clean background noise from video tracks
- `Add Watermark in Videos.bat` → Add text watermark to videos (bulk processing)

## ⚙️ Simple Setup Must Required  
1. Clone this repository:  
   ```
   git clone https://github.com/Munna-Soft/FFmpeg-Batch-Tools-Collection.git
   ```  
   **or** download the repository as a `.zip` & extract with winrar or 7zip.  
2. Run the `Master Version Toolkit AIO.bat` directly from Command Prompt or simply double-click.
3. Firstly Run Command **1** & follow terminal instruction for dependency setup.
4. Once dependency setup complete then run any tools if you want.
5. If you face any issues or request any other tools; please, contact me.
